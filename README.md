## What I build

### SIMARU — hospital asset inspection (RS UMMI Bogor)

While interning at RS UMMI Bogor, I built an app that lets technicians audit medical equipment on the wards. The design goal was simple: fewer steps, less typing, faster fieldwork.

- Scan a QR code on the equipment.
- Record condition with taps, not forms.
- Attach a photo when something is damaged.

### Digital Skyboard — airport flight information display

Terminal screens that must be readable from across the hall. Five Docker containers, a TLS gateway, and a design that favors clarity over decoration.

- Poll flight schedules every 30 seconds.
- Chime on boarding-status changes.
- Operator dashboard protected by Sanctum.

[Source ↗](https://github.com/AryaWgna/Digital-Skyboard-Announcement) · [Case study ↗](https://arya-wiguna.my.id/work/digital-skyboard-announcement)

### StreamEly — self-hosted VOD catalog

A personal project to organise a movie/TV library. The UI keeps the catalog calm: a clean grid, a simple player, and recommendations based on genre similarity.

- Custom Bun reverse proxy.
- 15,000+ records indexed in memory.
- Client-side Jaccard similarity scoring.
