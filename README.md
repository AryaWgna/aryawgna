### SIMARU — hospital asset inspection (RS UMMI Bogor)

Designed for technicians who audit equipment on the wards. The interface trims every unnecessary step.

- Scan the QR code on the equipment.
- Record condition with a few taps.
- Attach a photo when something is damaged.

Terminal screens that have to be readable from across the hall: clear type, clear states, no decoration.

- Poll flight schedules every 30 seconds.
- Chime on boarding-status changes.
- Operator dashboard protected by Sanctum.

### StreamEly — self-hosted VOD catalog

A calm way to browse a large library: clean grid, simple player, genre-based recommendations.

- Custom Bun reverse proxy.
- 15,000+ records indexed in memory.
- Client-side Jaccard similarity scoring.
